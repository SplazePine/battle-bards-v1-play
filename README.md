# Battle Bards — private test build

A private test build of **Battle Bards** made by Splazetown for **Pine**, who came up with the game idea, and Splaze, so they can play-test it on a PC.

It isn't released or announced yet. Please don't share the link.

**How to play:** press PLAY, pick Vespera, then press **G H J K** (or the gamepad d-pad) as each note reaches the line. **Space** (or RB) fires your special when the meter is full. **Esc** pauses. **O** opens SETTINGS (music + sound effects sliders); CONTROLS remaps keys. EASY is the default rival.
